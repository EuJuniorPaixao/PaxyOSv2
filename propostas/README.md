# propostas/

Propostas em rascunho ou já enviadas, pra leads que ainda não fecharam.

Quando o lead fechar, mover a proposta pra `clientes/<Nome>/` e criar a
pasta do projeto com `/novo-projeto`.

Toda proposta segue a identidade da marca (`identidade/design-guide.md`):
fundo escuro, verde `#5DE391` como acento, Space Grotesk no título,
logo no header.
